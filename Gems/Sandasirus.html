Generic

Description

Sandasirus is a transparent, fiery-looking stone with gold-like drops sparkling within. ¹ The more stars it contains, the more precious it is.

Sandasirus occurs in India, at a place with the same name. Gold drops appear to sparkle inside it as if in a transparent flame. It is generally agreed that the greater number of stars, the higher the value.
