Generic

Description

Light passes through Melichrysus as through pure honey seen against gold. ¹

Sources

1. St. Isidore of Seville — Etymologies, Book XVI, XV.6

Melichrysus is so named because this gem allows light to pass through it as if it were pure honey (mel) seen through gold.
