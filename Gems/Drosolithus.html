Drosolithus

Drosolithus

NamesDrosolithus; ¹ Drosolitus. ²
AppearanceVariegated, or varied in color. ¹ ²

Drosolithus, also called Drosolitus, is a variegated stone that sweats when brought near fire. ¹ ²

Generic

Description

Drosolithus is variegated and takes its name from a dew-like sweat that it gives off near fire. ¹ ²

Properties

When placed close to fire, Drosolithus emits something like sweat. ¹ ²

Sources

1. St. Isidore of Seville — Etymologies XVI, XII.2

Open cited source

Drosolithus is a variegated gem. The reason for its name is that if it is placed near the fire it emits something like sweat.

2. Camillo Leonardi — Speculum Lapidum

Open cited source

Drosolitus is varied-colored stone, from which it takes its name. If placed close to fire, it seems to emit a kind of sweat.
